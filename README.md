# Hou Yi Chia — Academic Website

Personal academic website of Hou Yi Chia, Research Fellow at the National University of Singapore.

**Website:** https://chiahouyi.github.io/

## About

This website presents my research in materials processing and advanced manufacturing, academic experience, and publications.

## Website Framework

Built using the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme and hosted on GitHub Pages.

## Local Development

The website can be previewed locally using Docker:

```bash
docker compose up
```

The local development server is available at http://localhost:8080.
